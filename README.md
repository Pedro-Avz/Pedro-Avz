## About Me

I'm a Software Engineer with a degree in Systems Analysis and Development from IFSP and an MBA in Software Engineering from USP/Esalq.

My main focus is backend development and distributed systems, working with Clojure, Python, Apache Kafka and event-driven architectures.

I have professional experience designing data models, implementing business rules, processing large volumes of data, and supporting systems in production. I also worked as a technical lead, helping a team of four developers with technical decisions, code reviews and delivery planning.

I enjoy understanding complex problems, evaluating different approaches and building solutions that make sense both technically and for the business.
